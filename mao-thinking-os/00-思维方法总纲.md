# 思维方法总纲：五层思考闭环

《毛泽东选集》看似是革命年代的文献汇编，但其内核是一套完整的**思维方法体系**。这套体系可以拆成五个层次，层层递进，构成一个从"认识世界"到"改造世界"再回到"自我修正"的闭环。

理解这五层的关系，比单独记住任何一个方法都重要。

## 第一层：认识世界（怎么看清楚一件事）

这是所有思考的起点，解决"我的判断从哪里来"的问题。四个方法层层深入：

| 方法 | 解决什么问题 | 一句话 |
|---|---|---|
| ① 实事求是 | 态度问题 | 从客观存在的事实出发，不从主观想象出发 |
| ② 调查研究 | 来源问题 | 没有调查，没有发言权；结论产生于调查的末尾 |
| ③ 实践认识论 | 验证问题 | 实践→认识→再实践→再认识，循环上升 |
| ④ 具体问题具体分析 | 方法问题 | 不同质的矛盾，用不同质的方法解决 |

**逻辑关系**：先摆正态度（实事求是）→ 再去掌握材料（调查研究）→ 在实践中检验和深化（实践认识论）→ 针对具体情况具体分析。这四个是"通用底座"，后面所有方法都建立在它们之上。

## 第二层：分析问题（怎么拆解一个复杂局面）

看清事实之后，需要把混沌的现实拆解成可操作的结构：

| 方法 | 解决什么问题 | 一句话 |
|---|---|---|
| ⑤ 矛盾分析法 | 找结构 | 任何复杂过程都有主要矛盾和次要矛盾 |
| ⑥ 阶级/利益相关方分析 | 找关系 | 谁是朋友、谁是敌人、谁是中立的 |
| ⑦ 趋势判断 | 找方向 | 从萌芽状态判断必然趋势，看见"桅杆尖头" |

**逻辑关系**：矛盾分析法拆"内部张力"，利益相关方分析拆"人的立场"，趋势判断定"时间方向"。三者合起来，就是对一个局面的完整诊断。

## 第三层：制定策略（怎么找到最优解）

诊断清楚之后，是策略选择——这是毛选最见功力的部分：

| 方法 | 解决什么问题 | 一句话 |
|---|---|---|
| ⑧ 抓主要矛盾 | 聚焦 | 捉住主要矛盾，一切问题迎刃而解 |
| ⑨ 集中优势兵力 | 资源配置 | 在关键点上形成绝对优势，各个击破 |
| ⑩ 持久战与阶段论 | 时间维度 | 战略上持久、战术上速决，分阶段推进 |
| ⑯ 战略战术两手 | 辩证施策 | 战略上藐视，战术上重视 |

**逻辑关系**：先用⑧找到"该打哪里"，再用⑨解决"怎么集中资源打赢"，再用⑩解决"长期节奏怎么安排"，⑯解决"心态与谨慎如何统一"。

## 第四层：组织执行（怎么把想法落地）

策略再好，落不了地等于零。这一层解决"怎么动员一群人把事做成"：

| 方法 | 一句话 |
|---|---|
| ⑪ 群众路线 | 从群众中来，到群众中去，无限循环、一次比一次正确 |
| ⑫ 一般号召+个别指导 | 提出普遍号召后，必须深入个别单位取得经验再推广 |
| ⑬ 弹钢琴/统筹全局 | 抓中心工作，同时围绕中心开展其他工作，十个指头都有节奏 |
| 抓紧 | 抓而不紧，等于不抓 |
| 胸中有数 | 任何质量都表现为数量，要有基本的数量分析 |

## 第五层：自我迭代（怎么避免自己成为问题）

这套体系最后指向使用者自身——这是它最容易被忽略、却最深刻的一层：

| 方法 | 一句话 |
|---|---|
| ⑭ 反对本本主义 | 不迷信书本和权威，理论必须与实际相结合 |
| ⑮ 批评与自我批评 | 经常清算自己的思想，去掉错误的东西 |
| 力戒骄傲 | 有了成绩也不要骄傲，这是领导者的原则问题 |

**为什么这一层最重要**：整部毛选的出发点，就是反对"主观主义"——即人的认识脱离实际、自我固化。如果使用者不能用这套方法反思自己，那么前面四层的方法都会被用歪。

## 五层闭环图

```
                ┌─────────────────────────────────┐
                │                                 │
                ▼                                 │
  【认识世界】→【分析问题】→【制定策略】→【组织执行】
   实事求是      矛盾分析      抓主要矛盾     群众路线
   调查研究      利益分析      集中兵力       一般+个别
   实践认识论    趋势判断      持久战阶段     弹钢琴/抓紧
   具体分析                                     │
                                                 │
                └──────【自我迭代】←─────────────┘
                   反对本本 / 批评自我批评 / 力戒骄傲
```

## 一句话总纲

> **从实际出发，具体问题具体分析，抓住主要矛盾，集中力量解决，在实践中检验，在循环中上升。**

这一句话，就是整套"思维操作系统"的内核。其余 16 个模型，都是这句话的展开。
