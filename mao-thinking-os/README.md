# 毛选思维操作系统（Mao's Thinking OS）

> 把《毛泽东选集》（1-5 卷，188 篇著作）蒸馏成一套**可调用的思维模型**。
> 目标不是背诵词句，而是遇到问题时，能按书中的思路去分析、判断、决策、行动。

## 这是什么

这套知识库把原著中分散在 188 篇文献里的**思想方法**提炼出来，组织成 16 个可操作的思维模型。每个模型都包含四层结构：

1. **一句话内核**——这个方法到底在说什么
2. **原文锚点**——出自哪篇、哪年，附真实引文（可回查「05-核心原著精选」）
3. **思考步骤**——遇到问题时，具体怎么一步步用
4. **应用与误区**——现代场景怎么用，以及最常见的误用

## 思维方法体系一览

整套方法按「**认识世界 → 分析问题 → 制定策略 → 组织执行 → 自我迭代**」五个层次展开，构成一个完整的思考闭环：

```
        ┌──────────── 自我迭代 ────────────┐
        │  ⑭反对本本主义  ⑮批评与自我批评   │
        │  ⑯战略战术两手  力戒骄傲          │
        └──────────────↑───────────────────┘
                       │
  认识世界 ──→ 分析问题 ──→ 制定策略 ──→ 组织执行
  ①实事求是      ⑤矛盾分析     ⑧抓主要矛盾    ⑪群众路线
  ②调查研究      ⑥利益分析     ⑨集中优势兵力  ⑫试点推广
  ③实践认识论    ⑦趋势判断     ⑩持久战阶段论 ⑬弹钢琴/统筹
  ④具体分析                    ⑯战略战术两手 抓紧/胸中有数
```

## 使用建议

- **不要把它当格言集**。每个方法都配了「思考步骤」，价值在于流程，不在于金句本身。
- **带着问题读**。先看「03-问题思考清单」，找到你当下的处境属于哪一类，再跳到对应模型。
- **原文与蒸馏对照读**。蒸馏是我的理解，原文才是源头；有疑问时回到「05-核心原著精选」核对。
