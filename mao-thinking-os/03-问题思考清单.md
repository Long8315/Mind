# 问题思考清单：遇到问题时该调用哪个方法

**这是整套知识库的使用入口。** 不要通读，而是找到你此刻的处境，按清单一步步思考。

---

## 场景 A：我要判断一件事的真假 / 做一个判断

适用：信息混乱、众说纷纭、不知道该信谁。

- [ ] **① 实事求是**：把"我认为"和"事实是"分开写。我的判断来源是事实还是想象？
- [ ] **② 调查研究**：我亲自调查过吗？调查对象是真的懂情况的人吗？有没有纲目？
- [ ] **③ 实践认识论**：这个认识验证过吗？材料够丰富、够真实吗？有没有去粗取精？
- [ ] **④ 具体问题具体分析**：这件事的特殊性在哪？我有没有直接套用一般经验？
- [ ] **⑭ 反对本本主义**：我信它，是因为它在实践里被证明对，还是因为权威说的？

> 顺序：先摆正态度（①）→ 掌握材料（②）→ 加工验证（③）→ 具体分析（④）→ 全程防教条（⑭）

---

## 场景 B：局面复杂，无从下手

适用：问题一大堆，感觉"如堕烟海"，不知道先做什么。

- [ ] **⑤ 矛盾分析法**：列出所有矛盾，不要笼统看"问题很多"。
- [ ] **⑧ 抓主要矛盾**：哪一个是"主要的"——解决了它其他都松动？我是否在用平均力？
- [ ] **⑥ 利益相关方分析**：谁是支持者/反对者/中间派？他们各自的真实利益是什么？
- [ ] **⑬ 胸中有数**：关键数字我掌握吗？（规模、比例、数量界限）

> 关键信号：觉得无从下手 = 还没找到主要矛盾。退一步重新分析结构，不要蛮干。

---

## 场景 C：资源有限，想集中力量办大事

适用：事情很多但资源不够，或者要跟强手竞争。

- [ ] **⑧ 抓主要矛盾**：先确定唯一的中心。
- [ ] **⑨ 集中优势兵力**：在关键点上形成绝对优势（至少 3 倍）？还是平摊了？
- [ ] **⑨ 选择薄弱点**：我打的是最容易突破且最有价值的那个点吗？
- [ ] **⑬ 弹钢琴**：抓住中心的同时，其他该照顾的方面"点到了"吗？
- [ ] **⑬ 抓紧**：我是"抓而不紧"——表面重视、实际没持续用力吗？

---

## 场景 D：面对强大对手 / 长期目标

适用：敌强我弱，或者目标需要长期努力，容易急躁或气馁。

- [ ] **⑩ 持久战**：我是否抱有不切实际的速胜幻想？接受"持久战"了吗？
- [ ] **⑩ 阶段论**：现在处于防御、相持还是反攻阶段？这个阶段该攻还是该守？
- [ ] **⑦ 趋势判断**：我看到的只是眼前强弱，还是力量对比的变化方向？"桅杆尖头"在哪？
- [ ] **⑯ 战略战术两手**：战略上敢不敢胜利？战术上够不够谨慎？有没有轻敌或畏敌？
- [ ] **⑨ 积小胜**：每个具体战役，我在集中优势快速取胜吗？

---

## 场景 E：要把想法落地 / 推动一群人做事

适用：方案有了，但推不动、落不了地。

- [ ] **⑫ 试点推广**：有没有先小范围验证？还是直接全面铺开？
- [ ] **⑪ 群众路线**：方案源头是一线意见吗？有没有回到相关方接受检验？
- [ ] **⑪ 领导骨干**：找到积极分子作为骨干了吗？团结中间、争取落后了吗？
- [ ] **⑬ 弹钢琴**：中心工作抓紧了吗？其他方面照顾了吗？
- [ ] **③ 实践认识论**：推广后收集反馈、循环改进了吗？

---

## 场景 F：事后复盘 / 出错之后

适用：事情结束了，无论成败，需要提取经验。

- [ ] **③ 实践认识论**：结果和预期的差距在哪？认识需要怎么修正？"从失败取得教训"了吗？
- [ ] **⑮ 批评与自我批评**：我诚实面对自己的判断失误了吗？
- [ ] **⑮ 力戒骄傲**：如果成功了，我是不是开始骄傲、停止学习？
- [ ] **⑮ 划清界限**：成绩和缺点各是几成？主流是成绩还是错误？
- [ ] **⑤ 矛盾转化**：主要矛盾/矛盾主要方面发生变化了吗？下阶段策略要调整吗？

---

## 万能五问（任何场景都可先用）

如果还不确定该用哪个方法，先问这五个问题，它们覆盖了整套系统的内核：

1. **事实是什么？**（实事求是 + 调查研究）
2. **矛盾在哪里？哪个是主要的？**（矛盾分析 + 抓主要矛盾）
3. **力量对比如何，趋势向哪？**（利益分析 + 趋势判断 + 持久战）
4. **我该集中力量打哪里？**（集中优势 + 弹钢琴 + 抓紧）
5. **事后怎么检验和修正？**（实践认识论 + 群众路线 + 自我批评）

> 这五问就是"毛选思维操作系统"的最小可用版本（MVP）。记不住全部模型，记住这五问也够用。
