## 一句话总纲

**心即理**（价值准则在内，不在外物）→ **知行合一**（真知必然包含行动）→ **致良知**（把内在准则推到具体事上）→ **事上磨**（在真实事务中验证并提纯）。

四句教是全书的收束：

> 无善无恶是心之体，有善有恶是意之动。知善知恶是良知，为善去恶是格物。【二九四】L3094
